# Security policy

`crapide` is a pre-release project. Security fixes are applied to the latest code on `main`; older commits and preview builds are not maintained as separate release lines.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/Cyril-Andre/crapide/security/advisories/new) to contact the maintainer. Include the affected version or commit, steps to reproduce, and the expected impact. Please do not publish exploit details in a public issue while a report is being assessed.
